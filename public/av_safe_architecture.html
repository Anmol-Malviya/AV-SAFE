02

Local Detection Engine

Fast first-pass risk analysis
EXTRACT

URL Feature Extraction

Parse and normalize the URL; derive lexical, host and path signals.

  • 24 engineered features
  • Length, entropy, token patterns
  • Hostname and redirect indicators
CLASSIFY

ML Classifier

Lightweight model inference using packaged, versioned model weights.

  • Phishing / benign prediction
  • Probability or confidence score
  • Versioned model artifacts
HEURISTICS

Security Rules Layer

Deterministic checks complement the model output.

  • Typosquatting and brand spoofing
  • Suspicious TLD / URL patterns
  • Entropy and obfuscation signals
DECISION

Risk Score Fusion

Combine model, rules and intelligence signals into a human-readable result.

  • Risk level and score
  • Explainable reason codes
  • Safe / suspicious / malicious
Enrichment · context retrieval · explainable response

Threat Data Sources

INGESTION

RECORDS

Threat Records

MongoDB stores normalized indicators, source metadata, timestamps and scan evidence.

VECTOR SEARCH

Qdrant Vector DB

Embeddings for semantic retrieval across advisories, reports and knowledge documents.

RAG

Context & Assistant

Hybrid exact + semantic retrieval, reranking, context assembly and cited LLM explanations.

1 · CollectThreat feeds and curated documents
2 · PrepareClean, validate, deduplicate and chunk
3 · IndexStore records and vector embeddings
4 · RetrieveExact + semantic search and rerank
5 · ExplainGrounded answer with evidence citations
Orchestration · persistence · continuous improvement
