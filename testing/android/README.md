# Android Test Discovery Suite

Native Android test sources are mapped to:
- Unit Tests: `android-app/app/src/test/java/com/phishguard/`
- Instrumentation Tests: `android-app/app/src/androidTest/java/com/phishguard/`

Run from the root or inside `android-app/`:
```bash
cd android-app && ./gradlew test
```
